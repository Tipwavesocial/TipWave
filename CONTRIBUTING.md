# Contributing to TipWave

Thanks for your interest in contributing! 🌊

## Getting Started

1. Fork the repo
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/tipwave`
3. Install dependencies: `pnpm install`
4. Create a branch: `git checkout -b feat/your-feature`

## Development

```bash
pnpm dev        # start local stack
pnpm test       # run all tests
pnpm lint       # lint & format check
```

## Pull Request Guidelines

- Keep PRs focused — one feature or fix per PR
- Add tests for new functionality
- Update docs if needed
- Run `pnpm lint` before submitting

## Commit Convention

We use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add recurring tip support
fix: correct paymaster gas estimate
docs: update quick start guide
```

## Reporting Issues

Open a GitHub Issue with:
- Clear title & description
- Steps to reproduce
- Expected vs actual behavior
- Environment (OS, Node version, etc.)

## Code of Conduct

Be kind. Be constructive. Build cool stuff together.
